# Guitar Choice Landing

Промоційний лендінг для гітарного магазину з інтерактивною 3D-моделлю інструмента, блочною структурою та інтеграцією з Headless CMS (Payload 3.0).

---

## 📁 Структура проєкту

* **`frontend/`** — клієнтська частина на Vite та Vanilla JS (модульна архітектура рендерингу блоків).
* **`cms/`** — Headless CMS на базі Payload 3.0 (Next.js App Router) з підключенням до PostgreSQL.
* **`backend/`** — автономний Express mock-сервер для розробки без запуску CMS.

---

## 🚀 Встановлення та запуск

### 1. Налаштування та запуск CMS

1. Перейдіть у директорію CMS та встановіть залежності:
   ```bash
   cd cms
   npm install
   ```

2. Створіть файл `cms/.env` із параметрами підключення:
   ```env
   DATABASE_URL=postgresql://<user>:<password>@<host>/<dbname>?sslmode=require
   PAYLOAD_SECRET=your_secret_key
   FRONTEND_URL=http://localhost:5173
   CMS_URL=http://localhost:3000
   PORT=3000
   ```

3. Запустіть сервер:
   ```bash
   npm run dev
   ```
   * Адмін-панель: `http://localhost:3000/admin`
   * Ендпоінт авто-ініціалізації даних: `http://localhost:3000/api/seed`

---

### 2. Запуск клієнтської частини (Frontend)

1. У новому терміналі перейдіть у папку фронтенду:
   ```bash
   cd frontend
   npm install
   ```

2. Запустіть dev-сервер:
   ```bash
   npm run dev
   ```
   * Лендінг відкриється за адресою: `http://localhost:5173`

---

## 📖 Інструкція: як користуватися проєктом

### Керування контентом через адмін-панель
1. Відкрийте `http://localhost:3000/admin` та увійдіть в акаунт адміністратора.
2. **Розділ «Сторінки» (Pages):**
   * Оберіть сторінку `Головна` (`/`).
   * У блоці **«Блоки»** можна змінювати тексти, додавати нові або приховувати існуючі блоки:
     * **Hero** — головний заголовок, опис, бейдж та кнопки переходу.
     * **Переваги (Features)** — картки майстерні (заголовок, опис, порядковий номер).
     * **Відгуки (Testimonials)** — відгуки музикантів, ім'я автора, роль та рейтинг.
     * **Контакти (Contacts)** — адреса львівського шоуруму, телефон, години роботи та кнопка переходу в магазин.
   * Натисніть **Save** праворуч угорі. Оновіть сторінку `http://localhost:5173` — контент оновиться миттєво.
3. **Розділ «Налаштування» (Globals -> Common):**
   * Редагування назви сайту, пунктів навігаційного меню та копірайту у футері.

---

### Взаємодія з інтерфейсом лендінгу
* **3D-візуалізація гітари:** інтерактивна 3D-модель у першому екрані підтримує обертання мишкою (360° огляд) та м'яко нахиляється слідом за курсором користувача.
* **Навігація:** клік по пунктах меню плавно скролить сторінку до відповідної секції з підсвічуванням поточного розділу.
* **Анімація при скролі:** картки та контент плавно спливають під час гортання сторінки (Scroll Reveal) через браузерний `IntersectionObserver`.

## 🔌 API Ендпоінти

| Метод | URL | Призначення |
|---|---|---|
| `GET` | `/api/common` | Глобальні налаштування сайту (меню, футер, посилання на магазин) |
| `GET` | `/api/page?path=/` | Отримання блоків для динамічного рендерингу сторінки |
| `GET` | `/api/seed` | Ініціалізація/скидання початкового контенту в базі даних |

---

## 🛠️ Стек технологій

* **Frontend:** Vanilla JS (ES Modules), Vite, CSS3, Google `<model-viewer>` (WebGL).
* **CMS & Backend:** Payload CMS 3, Next.js App Router, Express (mock).
* **База даних:** PostgreSQL (Neon Serverless).
